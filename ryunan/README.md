# Pokémon Ryunan — Regional Guide

Static Vietnamese encyclopedia and travel guide for the fictional Pokémon Ryunan region.

## Run locally
Open `index.html` in a browser. Supplied images are stored in `assets/` as optimized WebP copies.

## Notes
- Uses only images supplied for this build.
- Missing map, Gym Leader, Gym architecture, Elite Four, and Champion images are represented by placeholders instead of fabricated or externally sourced art.
- Route number groups are listed; exact origin/destination/waypoints remain pending a canonical map/reference.
