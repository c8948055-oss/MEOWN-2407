# Ryunan image assets

This directory is the destination for the optimized WebP images supplied for the Ryunan guide.

Copy the contents of the accompanying `assets/` folder from the Ryunan site bundle into this directory. The filenames expected by `index.html` are:

- `professor-takahashi.webp`
- `professor-tsukishiro.webp`
- `professor-kurosawa.webp`
- `professor-hanazawa.webp`
- `professor-hoshizora.webp`
- `professor-minazuki.webp`
- `professor-iwasaki.webp`
- `professor-midorikawa.webp`
- `institute-takahashi.webp`
- `institute-tsukishiro.webp`
- `institute-kurosawa.webp`
- `institute-hanazawa.webp`
- `institute-hoshizora.webp`
- `institute-minazuki.webp`
- `institute-iwasaki.webp`
- `institute-midorikawa.webp`
- `kurogane-hq.webp`

The current GitHub branch includes the page and deployment wiring, but the binary WebP files are provided separately in the ZIP bundle and still need to be added to this folder before the professor/institute images display on the published page.

Map, Gym Leader, Gym architecture, Elite Four, and Champion art were not present in the uploaded source set, so those sections intentionally use text placeholders.
